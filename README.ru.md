# Пробег курсора (Mouse Odometer)

Минималистичный виджет для Windows, который считает, сколько ты «проехал» мышью — на рабочем столе и в играх.

![Версия](https://img.shields.io/badge/version-1.3-blue) ![Лицензия](https://img.shields.io/badge/license-MIT-green)

[English version](README.md)

## Что показывает

- Пробег курсора в километрах и метрах
- Клики ЛКМ/ПКМ
- Прокрутку колеса в метрах и километрах (5 см за один щелчок)
- Достижения: 100 м → 500 м → 1 км → 5 км → 10 км → 21,1 км → 42,195 км → 100 км
- Сравнения: автобус, футбольное поле, круг стадиона, марафон
- Прогресс-бар «До Луны» (384 400 км)

## Запуск

1. Скачай `Mouse Odometer.exe` из раздела **Releases**.
2. Запусти — установка не нужна, права администратора тоже.
3. Подходит Windows 10/11, .NET Framework 4.8 уже в системе.

Виджет живёт на рабочем столе и не всплывает поверх окон. Перетаскивается левой кнопкой.
Правый клик — сброс, автозапуск, язык, поддержка, выход. Данные хранятся в `%APPDATA%\MouseOdometer`.

## Язык

Интерфейс переключается сам: русский на русской Windows, английский на остальных.
Поменять можно в любой момент в контекстном меню.

## Сборка

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /target:winexe /codepage:65001 /win32icon:app.ico /out:"Mouse Odometer.exe" MouseOdometer.cs
```

Один файл, без NuGet и без .NET SDK — достаточно компилятора, который уже есть в Windows.
